# AgentScope

Research and a static site about AI coding agents, their prompts, models,
execution harnesses and agent-to-agent delegation.

## Local preview

Serve `site` with any static file server. The current
interactive study is `site/index.html`.

## GitHub Pages

`.github/workflows/deploy-pages.yml` publishes the static site on pushes to
`main`. In the repository settings, set **Pages → Build and deployment →
Source** to **GitHub Actions**. The workflow deploys the contents of
`site`.

The study marks unverified capabilities explicitly. Its GitHub language and
star snapshots are dated and change over time.
