# 09. Comparativa global

| Variable causal | Intervención |
|---|---|
| Modelo | mismo harness, snapshot distinto |
| Prompt | mismo modelo/harness, una versión de prompt |
| Harness | mismo modelo/API y política, loop distinto |
| Contexto | misma tarea, estrategia/presupuesto distinto |
| Skills/subagentes | factorial con y sin cada capa |
| Permisos | misma sandbox/ACL, documentada |

No existe porcentaje universal del efecto. Harness define acciones posibles y bucle; prompt condiciona prioridad; modelo condiciona calidad de selección/generación. La interacción impide una suma sencilla.

“Oeste” frente a “China” se compara en dimensiones verificables: licencia, disponibilidad, repo, APIs, versión, modelo y código publicado. No se infiere calidad o cultura por país. Qwen Code, Kimi Code, MiniMax Code, Trae Agent, ZCode y MiMo Code tienen proyectos primarios identificables; DeepSeek Harness y Baidu Comate tienen evidencia de producto, pero sus fuentes de runtime/prompts no quedaron fijadas. Doubao, Hunyuan, ERNIE, DeepSeek, GLM y MiMo pueden nombrar familias/modelos, no necesariamente agentes. Tencent CodeBuddy no se atribuye a Hunyuan sin evidencia directa.
